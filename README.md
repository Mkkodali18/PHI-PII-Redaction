# PHI-PII Redaction Pipeline

A cybersecurity project that detects and redacts Personally Identifiable Information (PII) from healthcare records using Python, Regular Expressions, and spaCy.

## Features
- Detect Email
- Detect Phone Number
- Detect Aadhaar Number
- Detect Date of Birth
- Redact sensitive information

## Technologies
- Python
- Regex
- spaCy
- FastAPI (Later)
- Streamlit (Later)
